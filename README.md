# Mushgame

My game. I am building it with [Tay's Sensible Lang](https://github.com/tornapart0/tays-sensible-lang).

Open this folder in VS Code and start editing `main.mylang`. Press Cmd+Shift+B to run it, or use:

```sh
python3 interpreter.py main.mylang
```

On Windows, use `py` instead of `python3`. Python 3.10 or newer is required. The language runtime is included, so this starter needs no extra packages.

`.wakatime-project` sets the Hackatime project name to Mushgame. The installed editor tracker uses the existing Hackatime configuration.
